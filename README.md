## Описание проекта
Программа представляет собой интерактивное приложение на языке Python с использованием библиотеки Pygame, визуализирующее систему частиц фейерверков. Реализована генерация снарядов, летящих вверх и взрывающихся на пике высоты с образованием множества осколков. Движение частиц рассчитывается по физической модели с учетом угасания прозрачности и изменяемой силы гравитации.

## Функциональные возможности
### Основной функционал
- Случайная автоматическая генерация фейерверков различных цветов.
- Ограничение времени жизни для снарядов и образующихся частиц.
- Плавное изменение прозрачности частиц с использованием альфа-канала по мере сгорания.
- Моделирование физики падения частиц под действием силы тяжести.

### Дополнительный функционал
- Ручной запуск ракеты в любую точку экрана по нажатию левой кнопки мыши.
- Изменение коэффициента гравитации в реальном времени с помощью клавиатуры.

## Требования к системе
- Python: 3.9 или выше
- Операционная система: Windows / macOS / Linux
- Библиотеки: pygame==2.6.1

## Установка и запуск
### 1. Клонирование репозитория
```bash
git https://github.com/Tsutaba/Firework_animation
cd Firework_animation
```

### 2. Создание и активация виртуального окружения
Для Windows:
```bash
python -m venv venv
venv\Scripts\activate
```
Для macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление
- Левая кнопка мыши — запуск ракеты с детонацией в точке клика.
- Стрелка ВВЕРХ — увеличение силы гравитации.
- Стрелка ВНИЗ — уменьшение силы гравитации.
